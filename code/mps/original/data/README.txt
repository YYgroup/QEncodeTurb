Author: Nikita Gourianov
Purpose: Data from MPS simulations done in "A Quantum Inspired Approach to Exploit Turbulence Structures (2021)" paper. 

This folder is structured in the following manner: /IncompNs2D/ contains the data resulting from the 2-D incompressible Navier-Stokes MPS simulations, whilst /IncompNs3D/ contains the data from the 3-D simulations. The naming of each file contains all necessary information about the field. E.g. "NsIncomp2DFieldOutL10C33Re200000mt500.mat" is the 2-D flow field discretised on a 1024x1024 square resulting from MPS simulations at bond-dimension 33, with the MPS-Reynolds number set to 200,000 (corresponding to Re=1000 in the manuscript) at time t=0.5 (same units as in the manuscript). While for instance "NsIncomp3DFieldOutL8C96Re5027mt100.mat" is the 3-D flow field discretised on a 256x256x256 cube resulting from MPS simulations at bond-dimension 96, with the MPS-Reynolds number set to 5,027 (corresponding to Re=800 in the manuscript) at time t=0.1 (same units as in the manuscript). 

The MPS of these .mat files can be extracted and inspected by means of the "/NS2DIncomp/reconstructFields.m" (for 2D flows) and "/NS3DIncomp/reconstructFields3D.m" (for 3D flows) MATLAB functions in the /code/PDE_matfiles/ folder. For instance, simply load "NsIncomp2DFieldOutL10C33Re200000mt500.mat" and recover its 2D flow fields by running "[UrC33mt500, VrC33mt500] = reconstructFields(u1,u2)".
